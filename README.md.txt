# Automotive Sales and Performance Dashboard

## 📌 Project Overview

The **Automotive Sales and Performance Dashboard** is an end-to-end data analytics project developed using **MySQL, SQL and Microsoft Power BI**.

The project analyzes automotive sales and business performance data to understand revenue, profit, vehicle sales, dealer performance, customer behavior, regional performance, sales channels, target achievement and service operations.

The project follows an end-to-end data analytics workflow:

**Excel/CSV → MySQL → SQL Analysis → Star Schema → Power BI → DAX → Interactive Dashboard**

---

## 🎯 Project Objective

The main objective of this project is to transform raw automotive business data into meaningful insights using SQL and Power BI.

The dashboard helps business users:

- Monitor overall sales performance
- Track revenue and profit
- Analyze vehicle model performance
- Compare regional performance
- Evaluate dealer performance
- Understand customer type contribution
- Analyze sales channels and payment modes
- Compare sales targets with achieved units
- Analyze service cost and service status

---

## 🛠️ Tools & Technologies

- **MySQL** – Database creation and data storage
- **SQL** – Data extraction, joins, filtering, aggregation and validation
- **Power BI** – Data modeling and interactive dashboard development
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Excel / CSV** – Source data
